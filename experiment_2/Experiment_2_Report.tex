\section{Objective}
State the objective of the experiment:
In this lab experiment, I implemented, trained, and compared multiple probabilistic and instance-based machine learning classifiers on the Spambase dataset. Specifically, I evaluated three Naive Bayes variants (Gaussian, Multinomial, and Bernoulli) alongside K-Nearest Neighbors (KNN). I also optimized hyperparameters using GridSearchCV and RandomizedSearchCV, compared indexing structures (KDTree vs BallTree), and conducted 5-fold Stratified Cross-Validation.

\section{Problem Statement}
Describe the problem, input, output, and objective:
Spam detection is a binary classification problem designed to filter automated commercial messages from legitimate emails based on word frequencies and character frequencies.
\begin{itemize}
\item \textbf{Input}: 57 continuous feature columns representing word frequencies (\texttt{word\_freq\_*}) and character frequencies (\texttt{char\_freq\_*}).
\item \textbf{Output}: Binary target label \texttt{spam} (0 for legitimate ham email, 1 for spam email).
\item \textbf{Objective}: Normalize features using MinMaxScaler, partition data into 80\% training and 20\% test splits, fit Naive Bayes variants and KNN classifiers, tune parameters, analyze ROC and PR curves, and compare runtime efficiencies.
\end{itemize}

\section{Data Preprocessing}

\item \textbf{Scaling}: Applied \texttt{MinMaxScaler} to compress feature values into the range $[0, 1]$.

\section{Machine Learning Algorithm}

Explain:
\begin{itemize}
\item \textbf{Gaussian Naive Bayes}: Assumes continuous features follow Gaussian distributions $P(x_i|y) = \frac{1}{\sqrt{2\pi\sigma_y^2}} \exp\left(-\frac{(x_i-\mu_y)^2}{2\sigma_y^2}\right)$.
\item \textbf{Multinomial Naive Bayes}: Suitable for word count frequencies, computing relative term frequencies across classes.
\item \textbf{Bernoulli Naive Bayes}: Operates on binary occurrence features, evaluating presence or absence of key terms.
\item \textbf{K-Nearest Neighbors (KNN)}: Classifies samples based on majority voting among $k$ nearest neighbors using Euclidean or Manhattan distances.
\item \textbf{GridSearchCV \& RandomizedSearchCV}: Systematically search hyperparameter spaces for $k$, distance metrics, and weighting schemes.
\end{itemize}
