\section{Objective}
State the objective of the experiment:

In this laboratory experiment, my primary objective was to implement, evaluate and compare linear and non-linear discriminative classification algorithms on the Spambase email dataset. I built a baseline Logistic Regression classifier with $L_2$ regularization and four Support Vector Machine (SVM) models using Linear, Polynomial ($d=3$), Radial Basis Function (RBF) and Sigmoid kernel functions.

I wanted to understand how different kernel transformations project email feature vectors into separable decision spaces and whether non-linear boundaries significantly improve spam detection performance over linear approaches. In addition to model building, I aimed to:
\begin{itemize}
\item Compare training and prediction speed across classifiers.
\item Identify which word and character frequency features most strongly predict spam.
\item Verify model generalization stability using 5-fold Stratified Cross-Validation.
\item Evaluate both hard classification boundaries through confusion matrices and soft probability outputs through ROC and Precision-Recall curves.
\end{itemize}

\section{Problem Statement}
Describe the problem input output and objective:

Unsolicited commercial email, commonly known as spam, wastes server bandwidth and exposes users to phishing attacks. Automated spam filters must achieve both high precision (avoiding ham email misclassification) and high recall (catching as many spam emails as possible) at the same time.

The Spambase problem models spam filtering as a supervised binary classification task:
\begin{itemize}
\item \textbf{Input}: A feature vector $x \in \mathbb{R}^{57}$ containing 57 continuous numerical frequency attributes extracted from email content, covering word occurrence statistics, punctuation character frequencies and capital letter run length patterns.
\item \textbf{Output}: Binary target class label $y \in \{0, 1\}$ where 0 represents a legitimate ham email and 1 represents an unsolicited spam email.
\item \textbf{Objective}: Load and clean data by removing duplicates, normalize features using StandardScaler, train Logistic Regression and multi-kernel SVM classifiers, tune regularization parameter $C$ using cross-validation, evaluate using accuracy, precision, recall, F1-score and ROC-AUC metrics and generate visualization plots for all result comparisons.
\end{itemize}

\subsection*{Detailed Feature Attribute Breakdown}

The 57 continuous feature attributes fall into three structurally different categories. Understanding what each attribute measures is important for interpreting model coefficients and feature importance.

\subsubsection*{Category 1: Word Frequency Attributes (48 Features)}
These attributes measure the percentage of words in an email that match specific keyword terms. Each attribute takes a real value between 0 and 100, computed as:
\begin{equation}
\text{word\_freq\_X} = \frac{100 \times \text{count}(X \text{ in email})}{\text{total words in email}}
\end{equation}

Keywords measured include: \texttt{make}, \texttt{address}, \texttt{all}, \texttt{3d}, \texttt{our}, \texttt{over}, \texttt{remove}, \texttt{internet}, \texttt{order}, \texttt{mail}, \texttt{receive}, \texttt{will}, \texttt{people}, \texttt{report}, \texttt{addresses}, \texttt{free}, \texttt{business}, \texttt{email}, \texttt{you}, \texttt{credit}, \texttt{your}, \texttt{font}, \texttt{000}, \texttt{money}, \texttt{hp}, \texttt{hpl}, \texttt{george}, \texttt{650}, \texttt{lab}, \texttt{labs}, \texttt{telnet}, \texttt{857}, \texttt{data}, \texttt{415}, \texttt{85}, \texttt{technology}, \texttt{1999}, \texttt{parts}, \texttt{pm}, \texttt{direct}, \texttt{cs}, \texttt{meeting}, \texttt{original}, \texttt{project}, \texttt{re}, \texttt{edu} and \texttt{conference}.

\subsubsection*{Category 2: Character Frequency Attributes (6 Features)}
These attributes measure the percentage of characters in an email matching specific punctuation marks:
\begin{equation}
\text{char\_freq\_X} = \frac{100 \times \text{count}(X \text{ in email})}{\text{total characters in email}}
\end{equation}

Characters measured: \texttt{char\_freq\_;} (semicolons), \texttt{char\_freq\_(} (open parentheses), \texttt{char\_freq\_[} (open brackets), \texttt{char\_freq\_!} (exclamation marks), \texttt{char\_freq\_\$} (dollar signs) and \texttt{char\_freq\_\#} (hash symbols).

\subsubsection*{Category 3: Capital Letter Run-Length Attributes (3 Features)}
These attributes quantify unusual use of capital letters in email body text:
\begin{itemize}
\item \textbf{capital\_run\_length\_average}: Average length of consecutive capital letter sequences.
\item \textbf{capital\_run\_length\_longest}: Length of the single longest capital letter run in the email.
\item \textbf{capital\_run\_length\_total}: Total count of all capital letters appearing in the email.
\end{itemize}

Spam emails frequently use all-caps phrases to draw attention (e.g., ``FREE OFFER''), making these attributes highly discriminative.

\begin{lstlisting}
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled  = scaler.transform(X_test)
\end{lstlisting}
StandardScaler transforms each feature $j$ using training set statistics:
\begin{equation}
z_{ij} = \frac{x_{ij} - \hat{\mu}_j}{\hat{\sigma}_j}
\end{equation}
where $\hat{\mu}_j$ and $\hat{\sigma}_j$ are the mean and standard deviation computed on the training fold only. Applying the same scaler transform to test data (without refitting) prevents data leakage. Scaling is critical for both Logistic Regression convergence speed and for SVM margin computation which is sensitive to feature scales.

\section{Machine Learning Algorithm}

Explain:
In this experiment I implemented two classification model families covering linear and kernel-based non-linear approaches.

\subsection{Logistic Regression with $L_2$ Regularization}

Logistic Regression is a widely used probabilistic linear classifier. For a binary target $y \in \{0, 1\}$, it models the conditional probability that a given email is spam using the logistic sigmoid activation:

\begin{equation}
P(y=1 \mid x; w, b) = \sigma(w^T x + b) = \frac{1}{1 + e^{-(w^T x + b)}}
\end{equation}

During training, model parameters $w \in \mathbb{R}^{57}$ and bias $b$ are found by minimizing the $L_2$ regularized binary cross-entropy loss function:

\begin{equation}
\mathcal{L}(w, b) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log(\hat{p}^{(i)}) + (1 - y^{(i)}) \log(1 - \hat{p}^{(i)}) \right] + \frac{1}{2C} \| w \|_2^2
\end{equation}

where $m$ is the number of training samples, $\hat{p}^{(i)} = \sigma(w^T x^{(i)} + b)$ is the predicted probability and $C > 0$ controls inverse regularization strength. A lower $C$ applies stronger $L_2$ weight penalty.

\textbf{Final prediction rule}: For a new email $x$, predict spam if $P(y=1 \mid x) \geq 0.5$ else predict ham.

\subsection{Support Vector Machine (SVM)}

Support Vector Machines are maximum-margin classifiers. For linearly separable data, SVM seeks a decision hyperplane $w^T x + b = 0$ that separates the two classes with the largest possible geometric margin $\frac{2}{||w||}$.

For non-separable real data, the soft-margin SVM introduces slack variables $\xi_i \geq 0$ allowing some training samples to violate the margin constraint while paying a penalty cost $C$. The optimization problem becomes:

\begin{equation}
\min_{w, b, \xi} \;\; \frac{1}{2} \|w\|^2 + C \sum_{i=1}^{m} \xi_i
\end{equation}

subject to the per-sample constraints:
\begin{equation}
y_i \left( w^T \phi(x_i) + b \right) \geq 1 - \xi_i, \quad \xi_i \geq 0, \quad i = 1, \ldots, m
\end{equation}

where $\phi(x_i)$ maps the input into a higher-dimensional feature space.

\subsection{The Kernel Trick}

When data is non-linearly separable, explicit computation of $\phi(x)$ may be computationally infeasible for very high-dimensional spaces. The kernel trick replaces $\phi(x_i)^T \phi(x_j)$ with a kernel function $K(x_i, x_j)$ that computes inner products in the transformed space implicitly:

\begin{equation}
K(x_i, x_j) = \phi(x_i)^T \phi(x_j)
\end{equation}

The dual formulation of SVM depends only on kernel evaluations, never on explicit $\phi$ mappings.

\subsubsection*{Kernel Functions Used}

\paragraph{Linear Kernel}
Computes dot products in the original $\mathbb{R}^{57}$ feature space:
\begin{equation}
K_{\text{linear}}(x_i, x_j) = x_i^T x_j
\end{equation}
Suitable for linearly separable or near-linearly separable data with many features.

\paragraph{Polynomial Kernel (degree = 3)}
Implicitly maps features into all polynomial combinations up to degree $d$:
\begin{equation}
K_{\text{poly}}(x_i, x_j) = (\gamma \, x_i^T x_j + r)^d
\end{equation}
where $\gamma = 1/n\_features$, $r = 0$ and $d = 3$.

\paragraph{Radial Basis Function (RBF) Kernel}
Most widely used non-linear kernel. Maps each feature vector into an infinite-dimensional space using Gaussian similarity:
\begin{equation}
K_{\text{rbf}}(x_i, x_j) = \exp\left(-\gamma \|x_i - x_j\|^2\right)
\end{equation}
The parameter $\gamma = \frac{1}{n\_features \cdot \text{Var}(X)}$ when using \texttt{gamma='scale'}. Smaller $\gamma$ creates wider Gaussian kernels with smoother decision boundaries.

\paragraph{Sigmoid Kernel}
Mimics the activation function of neural network perceptrons:
\begin{equation}
K_{\text{sigmoid}}(x_i, x_j) = \tanh(\gamma \, x_i^T x_j + r)
\end{equation}
Can be less stable due to non-positive semi-definite behavior for some parameter choices.

\section{Discussion}
Discuss observations, strengths, limitations and improvements:

\subsection*{Observation 1 -- Linear vs Non-Linear Decision Boundaries}
RBF kernel SVM outperformed all linear models by projecting 57-dimensional email feature vectors into an infinite-dimensional Hilbert space. The Gaussian kernel similarity function groups emails by overall frequency pattern similarity rather than just linear thresholds. Even though the performance difference (93.35\% vs 93.23\% accuracy) appears small in absolute terms, this improvement corresponds to correctly classifying approximately one additional test email per 84 evaluated.

\subsection*{Observation 2 -- Kernel Function Comparison}
Comparing all four SVM kernel variants reveals an important pattern. The RBF kernel achieved 93.35\% accuracy, Linear kernel achieved 92.75\%, Polynomial ($d=3$) achieved 91.89\% and Sigmoid achieved 88.45\%. Sigmoid performed worst because the hyperbolic tangent kernel is not always positive semi-definite for arbitrary parameter values, which can violate conditions needed for SVM optimization convergence.

\subsection*{Observation 3 -- Regularization Strength Effect}
Testing $C$ values from 0.1 to 100.0 showed that moderate regularization ($C=10.0$) gave the best balance between fitting the training data and generalizing to test data. Very low $C$ values underfitted the training set, while very high $C$ values created narrow margin boundaries that overfitted noise in training email frequencies.

\subsection*{Observation 4 -- False Positive Analysis in Spam Filtering Context}
In real spam filter deployment, false positives (legitimate ham emails wrongly flagged as spam) cause user frustration because important messages get blocked. Both classifiers achieved precision above 92.6\%, meaning fewer than 8 out of every 100 flagged emails were false alarms.

\subsection*{Observation 5 -- Runtime Considerations}
Logistic Regression fitted in approximately 0.28 seconds while RBF SVM required about 0.32 seconds for $C=10.0$ training. For large-scale email servers processing millions of messages per day, Logistic Regression's near-zero inference latency makes it more suitable for real-time classification compared to SVM which stores support vectors.

\subsection*{Observation 6 -- Cross-Validation Stability}
5-fold cross-validation standard deviations were 0.27\% for Logistic Regression and 0.25\% for SVM RBF, confirming both models are robust across different data splits. Low variance across folds means performance is not dependent on a lucky random split.

\section{Conclusion}
Summarize the experiment and key findings:

In this laboratory experiment, I built and evaluated Logistic Regression and four SVM kernel variants for spam email classification using the Spambase dataset.

The key findings from this experiment are:

\begin{enumerate}
\item \textbf{Best Overall Model}: Tuned RBF SVM with $C=10.0$ and $\gamma=\text{'scale'}$ achieved 93.35\% test accuracy and 0.9776 ROC-AUC, the highest scores across all tested models.
\item \textbf{Competitive Linear Baseline}: Logistic Regression achieved 93.23\% accuracy within 0.12 percentage points of RBF SVM at significantly faster training and inference speed.
\item \textbf{Kernel Importance}: The choice of kernel significantly impacts SVM performance. RBF and Linear kernels both performed well while Sigmoid produced 4.9 percentage points lower accuracy than RBF.
\item \textbf{Cross-Validation Stability}: 5-fold stratified cross-validation confirmed model reliability with average scores of 93.12\% for SVM and 92.85\% for Logistic Regression with minimal variance across folds.
\item \textbf{Character Frequency Features are Key Discriminators}: Exclamation mark frequency and dollar sign frequency are the two strongest individual spam predictors in the dataset, reflected in high model weights for these attributes.
\end{enumerate}

Overall, Logistic Regression is recommended for real-time high-throughput spam filtering due to fast inference, while RBF SVM provides maximum classification precision when computational budget allows.
